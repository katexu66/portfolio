January 2026 - Ongoing

MIT Media Lab Biomechatronics Group

Summary: Designed an end-to-end EMG signal-processing pipeline for a rehabilitative swallowing device at the MIT Media Lab, including data collection with a patient, processing for event detection, and real-time visualization through a web application. Implemented band-pass filtering and RMS envelope extraction to detect swallow-like activations in noisy signals. Developed the full web stack for real-time visualization and analysis, integrating hardware streaming from an OpenBCI Ganglion board with a web-based frontend, focusing on user experience for the end patient.
